# Comprehensive SEO, AI GEO & Multilingual Kannada Optimization Plan ## Problem & Background Context Karnata.in is a multi-hub state information portal for Karnataka covering real-time Weather/KSNDMC, Dam Levels, APMC Mandi rates, Gold rates, Cabinet Ministers, Government Orders & Officer Transfers, Government Schemes (Gruha Lakshmi, Bhoomi RTC, GBA), and District Guides. To ensure all pages rank at the top of Google Search for both **Kannada queries** (e.g. `ಕರ್ನಾಟಕ ಹವಾಮಾನ`, `ಇಂದಿನ ಚಿನ್ನದ ದರ`, `ಜಲಾಶಯಗಳ ನೀರಿನ ಮಟ್ಟ`, `ಗೃಹಲಕ್ಷ್ಮಿ ಸ್ಟೇಟಸ್ ಚೆಕ್`) and **English queries**, and are optimally indexed for **AI Search Engines / GEO (Google Gemini, Perplexity, ChatGPT, Claude, Copilot)**, a complete site-wide optimization is required. --- ## Proposed Changes ### 1. Multilingual Kannada + English SEO Metadata Suite Every public hub and article page will receive optimized metadata: - **High-Intent Kannada ``**: Dual-language title incorporating primary Kannada search intent and brand identity. - **`<meta name="description">`**: 150-160 character rich Kannada meta description with target keywords. - **`<meta name="keywords">`**: Dual Kannada + English high-volume search terms. - **`<link rel="canonical">`**: Canonical URL pointing to canonical HTTPS URL. ### 2. GEO (Generative Engine Optimization & Regional Metadata) - **Geographic Tags**: ```html <meta name="geo.region" content="IN-KA" /> <meta name="geo.placename" content="Karnataka, India" /> <meta name="geo.position" content="12.9716;77.5946" /> <meta name="ICBM" content="12.9716, 77.5946" /> ``` - **AI Search Directives**: ```html <meta name="robots" content="index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1" /> <meta name="googlebot" content="index, follow, max-snippet:-1, max-image-preview:large" /> <meta name="bingbot" content="index, follow, max-snippet:-1, max-image-preview:large" /> ``` ### 3. OpenGraph & Social Media Metadata - `og:locale` set to `kn_IN` with alternate `en_IN`. - `og:site_name` set to `ಕರ್ನಾಟಕ ಲೈವ್ ಮಾಹಿತಿ ಕೇಂದ್ರ — Karnata.in`. - `twitter:card` set to `summary_large_image`. - Verified OpenGraph image URLs. ### 4. Structured Data (JSON-LD Schemas) - **`WebSite` Schema**: On homepage with Google Sitelinks SearchBox. - **`Organization` / `GovernmentOrganization` Schema**: Establishing official entity graph. - **`BreadcrumbList` Schema**: On all subpages for rich Google breadcrumbs. - **`FAQPage` Schema**: On pages with accordions (`weather.html`, `gold-rate.html`, `dam-levels.html`, articles). - **`NewsArticle` / `Article` Schema**: On `karnataka-stories.html` and all `article/*.html` pages. ### 5. Sitemap & Robots.txt Hygiene - **`sitemap.xml`**: Remove `/admin*`, `/cms*`, `/studio*` from indexing; include all 100+ public pages (31 district portals, 12 dam pages, GBA pages, calculator tools, and articles) with valid priority and `<lastmod>` dates. - **`robots.txt`**: Explicitly disallow internal admin paths while giving full access to `Googlebot`, `Bingbot`, `GPTBot`, `PerplexityBot`,
