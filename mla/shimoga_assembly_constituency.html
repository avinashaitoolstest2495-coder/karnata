📰 ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಚಿತ್ರಣ ಕ್ಷೇತ್ರ ಮಾಹಿತಿ

ಶಿವಮೊಗ್ಗ ಕ್ಷೇತ್ರ ಚುನಾವಣೆ ವರದಿ: ಶಾಸಕ Channabasappa ( Chenni ) ಜಯದ ಲೆಕ್ಕಾಚಾರ ಮತ್ತು ರಾಜಕೀಯ ಪಯಣ

ಕರ್ನಾಟಕ ಜಿಲ್ಲೆಯ ರಾಜಕೀಯ ನಕ್ಷೆಯಲ್ಲಿ ಶಿವಮೊಗ್ಗ ವಿಧಾನಸಭಾ ಕ್ಷೇತ್ರವು (ಕ್ಷೇತ್ರ ಸಂಖ್ಯೆ #113) ವಿಶಿಷ್ಟ ಸ್ಥಾನ ಪಡೆದಿದೆ. ಸಾಮಾನ್ಯ ಕ್ಷೇತ್ರದಲ್ಲಿ ಕಳೆದ 2023ರ ಕರ್ನಾಟಕ ವಿಧಾನಸಭಾ ಚುನಾವಣೆಯಲ್ಲಿ ಅತ್ಯಂತ ರೋಚಕ ಚುನಾವಣಾ ಕದನ ಜರುಗಿತ್ತು. ಮತ ಎಣಿಕೆಯ ಅಂತಿಮ ಹಂತದಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ ಜನಪ್ರಿಯ ನಾಯಕ Channabasappa ( Chenni ) ಅವರು ಜನಾದೇಶ ಪಡೆಯುವಲ್ಲಿ ಯಶಸ್ವಿಯಾಗಿ ಪ್ರಸ್ತುತ ಶಾಸಕರಾಗಿ ಕರ್ತವ್ಯ ನಿರ್ವಹಿಸುತ್ತಿದ್ದಾರೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಅಂಕಿಅಂಶಗಳ ಪ್ರಕಾರ Channabasappa ( Chenni ) ಅವರು ಒಟ್ಟು 96,490 ಮತಗಳನ್ನು ಗಳಿಸುವ ಮೂಲಕ ಶೇಕಡಾ 54.0% ಮತ ಹಂಚಿಕೆ ಪಡೆದಿದ್ದಾರೆ.

ಕಳೆದ ಚುನಾವಣೆಯ ಮತಗಳ ಲೆಕ್ಕಾಚಾರವನ್ನು ಪರಿಶೀಲಿಸಿದಾಗ, ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ Channabasappa ( Chenni ) ಮತ್ತು ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಎಚ್. ಸಿ. Yogesh ನಡುವೆ ತೀವ್ರ ಸ್ಪರ್ಧೆ ಏರ್ಪಟ್ಟಿತ್ತು. ಅಂತಿಮವಾಗಿ Channabasappa ( Chenni ) ಅವರು 27,674 ಮತಗಳ ಸ್ಪಷ್ಟ ಗೆಲುವಿನ ಅಂತರದೊಂದಿಗೆ ತಮ್ಮ ಎದುರಾಳಿ ಎಚ್. ಸಿ. Yogesh ಅವರನ್ನು ಪರಾಭವಗೊಳಿಸಿದರು. ಎರಡನೇ ಸ್ಥಾನ ಪಡೆದ ಕಾಂಗ್ರೆಸ್ (INC) ಅಭ್ಯರ್ಥಿ ಎಚ್. ಸಿ. Yogesh ಅವರು 68,816 ಮತಗಳನ್ನು ಪಡೆದು ಗಮನಾರ್ಹ ಸಾಧನೆ ಮಾಡಿದರು. ಈ ಚುನಾವಣೆಯಲ್ಲಿ ಕ್ಷೇತ್ರದಲ್ಲಿ ಶೇಕಡಾ 75.4% ಮತದಾನ ದಾಖಲಾಗಿತ್ತು.

ಶಿವಮೊಗ್ಗ ಕ್ಷೇತ್ರದ ಚುನಾವಣಾ ಇತಿಹಾಸವು ಅತ್ಯಂತ ವೈವಿಧ್ಯಮಯವಾಗಿದೆ. 1978ರಿಂದ 2023ರವರೆಗೆ ನಡೆದ ಒಟ್ಟು 11 ಸಾರ್ವತ್ರಿಕ ಚುನಾವಣೆಗಳಲ್ಲಿ ಪ್ರಮುಖವಾಗಿ ಬಿಜೆಪಿ (BJP) (4 ಬಾರಿ), ಕಾಂಗ್ರೆಸ್ (INC) (2 ಬಾರಿ), ಜನತಾ ಪಕ್ಷ (JNP) (2 ಬಾರಿ), ಜೆಡಿಎಸ್ (JD-S) (1 ಬಾರಿ) ಮತದಾರರ ಪ್ರಮುಖ ಬೆಂಬಲ ಪಡೆದುಕೊಂಡಿವೆ. ಗತಕಾಲದ ಚುನಾವಣೆಗಳ ಫಲಿತಾಂಶಗಳನ್ನು ನೋಡಿದರೆ 2018ರ ಚುನಾವಣೆಯಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ ಕೆ. ಎಸ್. ಈಶ್ವರಪ್ಪ ಅವರು (+46,107 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2013ರ ಚುನಾವಣೆಯಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಕೆ. ಬಿ. Prasannakumar ಅವರು (+278 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2008ರ ಚುನಾವಣೆಯಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ ಕೆ. ಎಸ್. ಈಶ್ವರಪ್ಪ ಅವರು (+32,419 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2004ರ ಚುನಾವಣೆಯಲ್ಲಿ ಜೆಡಿಎಸ್ (JD-S) ಪಕ್ಷದ ಡಾ. ಮಹಾದೇವಪ್ಪ Hc ಅವರು (+14,257 ಮತಗಳ ಅಂತರ) ಯಶಸ್ವಿಯಾಗಿ ಶಾಸಕರಾಗಿ ಆಯ್ಕೆಯಾಗಿ ಜನಸೇವೆ ಸಲ್ಲಿಸಿದ್ದರು.

ಒಟ್ಟಾರೆಯಾಗಿ ಶಿವಮೊಗ್ಗ ಶಾಸನಸಭಾ ಕ್ಷೇತ್ರವು ಮತದಾರರ ಪ್ರಬುದ್ಧ ತೀರ್ಪಿಗೆ ಹಾಗೂ ರಾಜಕೀಯ ಮರುಸಂಘಟನೆಗೆ ಸಾಕ್ಷಿಯಾಗಿದೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಮುಕ್ತ ಮತ್ತು ನ್ಯಾಯಸಮ್ಮತ ದಾಖಲೆಗಳ ಆಧಾರದ ಮೇಲೆ ರಚಿತವಾದ ಈ ವರದಿಯು ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಪ್ರಗತಿ ಹಾಗೂ ಮುಂದಿನ ದಿನಗಳ ರಾಜಕೀಯ ಪಥಕ್ಕೆ ದಿಕ್ಸೂಚಿಯಾಗಿದೆ.

ಮಾಹಿತಿಯ ಮೂಲಗಳು: ಚುನಾವಣಾ ಆಯೋಗ, ಸಂಬಂಧಿತ ಅಧಿಕೃತ ಮೂಲಗಳು
