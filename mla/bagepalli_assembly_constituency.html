📰 ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಚಿತ್ರಣ ಕ್ಷೇತ್ರ ಮಾಹಿತಿ

ಬಾಗೇಪಲ್ಲಿ ಕ್ಷೇತ್ರ ಚುನಾವಣೆ ವರದಿ: ಶಾಸಕ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಜಯದ ಲೆಕ್ಕಾಚಾರ ಮತ್ತು ರಾಜಕೀಯ ಪಯಣ

ಕರ್ನಾಟಕ ಜಿಲ್ಲೆಯ ರಾಜಕೀಯ ನಕ್ಷೆಯಲ್ಲಿ ಬಾಗೇಪಲ್ಲಿ ವಿಧಾನಸಭಾ ಕ್ಷೇತ್ರವು (ಕ್ಷೇತ್ರ ಸಂಖ್ಯೆ #140) ವಿಶಿಷ್ಟ ಸ್ಥಾನ ಪಡೆದಿದೆ. ಸಾಮಾನ್ಯ ಕ್ಷೇತ್ರದಲ್ಲಿ ಕಳೆದ 2023ರ ಕರ್ನಾಟಕ ವಿಧಾನಸಭಾ ಚುನಾವಣೆಯಲ್ಲಿ ಅತ್ಯಂತ ರೋಚಕ ಚುನಾವಣಾ ಕದನ ಜರುಗಿತ್ತು. ಮತ ಎಣಿಕೆಯ ಅಂತಿಮ ಹಂತದಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಜನಪ್ರಿಯ ನಾಯಕ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಅವರು ಜನಾದೇಶ ಪಡೆಯುವಲ್ಲಿ ಯಶಸ್ವಿಯಾಗಿ ಪ್ರಸ್ತುತ ಶಾಸಕರಾಗಿ ಕರ್ತವ್ಯ ನಿರ್ವಹಿಸುತ್ತಿದ್ದಾರೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಅಂಕಿಅಂಶಗಳ ಪ್ರಕಾರ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಅವರು ಒಟ್ಟು 82,128 ಮತಗಳನ್ನು ಗಳಿಸುವ ಮೂಲಕ ಶೇಕಡಾ 47.6% ಮತ ಹಂಚಿಕೆ ಪಡೆದಿದ್ದಾರೆ.

ಕಳೆದ ಚುನಾವಣೆಯ ಮತಗಳ ಲೆಕ್ಕಾಚಾರವನ್ನು ಪರಿಶೀಲಿಸಿದಾಗ, ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಮತ್ತು ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ ಸಿ. Muniraju ನಡುವೆ ತೀವ್ರ ಸ್ಪರ್ಧೆ ಏರ್ಪಟ್ಟಿತ್ತು. ಅಂತಿಮವಾಗಿ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಅವರು 19,179 ಮತಗಳ ಸ್ಪಷ್ಟ ಗೆಲುವಿನ ಅಂತರದೊಂದಿಗೆ ತಮ್ಮ ಎದುರಾಳಿ ಸಿ. Muniraju ಅವರನ್ನು ಪರಾಭವಗೊಳಿಸಿದರು. ಎರಡನೇ ಸ್ಥಾನ ಪಡೆದ ಬಿಜೆಪಿ (BJP) ಅಭ್ಯರ್ಥಿ ಸಿ. Muniraju ಅವರು 62,949 ಮತಗಳನ್ನು ಪಡೆದು ಗಮನಾರ್ಹ ಸಾಧನೆ ಮಾಡಿದರು. ಈ ಚುನಾವಣೆಯಲ್ಲಿ ಕ್ಷೇತ್ರದಲ್ಲಿ ಶೇಕಡಾ 75.4% ಮತದಾನ ದಾಖಲಾಗಿತ್ತು.

ಬಾಗೇಪಲ್ಲಿ ಕ್ಷೇತ್ರದ ಚುನಾವಣಾ ಇತಿಹಾಸವು ಅತ್ಯಂತ ವೈವಿಧ್ಯಮಯವಾಗಿದೆ. 1978ರಿಂದ 2023ರವರೆಗೆ ನಡೆದ ಒಟ್ಟು 11 ಸಾರ್ವತ್ರಿಕ ಚುನಾವಣೆಗಳಲ್ಲಿ ಪ್ರಮುಖವಾಗಿ ಕಾಂಗ್ರೆಸ್ (INC) (4 ಬಾರಿ), ಬಿಜೆಪಿ (BJP) (4 ಬಾರಿ), ಪಕ್ಷೇತರ (IND) (1 ಬಾರಿ), ಜನತಾ ದಳ (JD) (1 ಬಾರಿ) ಮತದಾರರ ಪ್ರಮುಖ ಬೆಂಬಲ ಪಡೆದುಕೊಂಡಿವೆ. ಗತಕಾಲದ ಚುನಾವಣೆಗಳ ಫಲಿತಾಂಶಗಳನ್ನು ನೋಡಿದರೆ 2018ರ ಚುನಾವಣೆಯಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಅವರು (+14,013 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2013ರ ಚುನಾವಣೆಯಲ್ಲಿ ಪಕ್ಷೇತರ (IND) ಪಕ್ಷದ ಎಸ್. ಎನ್. Subbareddy ( Chinnakayalapalli ) ಅವರು (+30,755 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2008ರ ಚುನಾವಣೆಯಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ Sampangi ಎನ್. ಅವರು (+938 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2004ರ ಚುನಾವಣೆಯಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ Prabhakara Bangera ಕೆ. ಅವರು (+12,821 ಮತಗಳ ಅಂತರ) ಯಶಸ್ವಿಯಾಗಿ ಶಾಸಕರಾಗಿ ಆಯ್ಕೆಯಾಗಿ ಜನಸೇವೆ ಸಲ್ಲಿಸಿದ್ದರು.

ಒಟ್ಟಾರೆಯಾಗಿ ಬಾಗೇಪಲ್ಲಿ ಶಾಸನಸಭಾ ಕ್ಷೇತ್ರವು ಮತದಾರರ ಪ್ರಬುದ್ಧ ತೀರ್ಪಿಗೆ ಹಾಗೂ ರಾಜಕೀಯ ಮರುಸಂಘಟನೆಗೆ ಸಾಕ್ಷಿಯಾಗಿದೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಮುಕ್ತ ಮತ್ತು ನ್ಯಾಯಸಮ್ಮತ ದಾಖಲೆಗಳ ಆಧಾರದ ಮೇಲೆ ರಚಿತವಾದ ಈ ವರದಿಯು ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಪ್ರಗತಿ ಹಾಗೂ ಮುಂದಿನ ದಿನಗಳ ರಾಜಕೀಯ ಪಥಕ್ಕೆ ದಿಕ್ಸೂಚಿಯಾಗಿದೆ.

ಮಾಹಿತಿಯ ಮೂಲಗಳು: ಚುನಾವಣಾ ಆಯೋಗ, ಸಂಬಂಧಿತ ಅಧಿಕೃತ ಮೂಲಗಳು
