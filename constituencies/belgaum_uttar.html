📰 ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಚಿತ್ರಣ ಕ್ಷೇತ್ರ ಮಾಹಿತಿ

ಬೆಳಗಾವಿ ಉತ್ತರ ಕ್ಷೇತ್ರ ಚುನಾವಣೆ ವರದಿ: ಶಾಸಕ ಆಸಿಫ್ ( ರಾಜು ) ಸೇಟ್ ಜಯದ ಲೆಕ್ಕಾಚಾರ ಮತ್ತು ರಾಜಕೀಯ ಪಯಣ

ಕರ್ನಾಟಕ ಜಿಲ್ಲೆಯ ರಾಜಕೀಯ ನಕ್ಷೆಯಲ್ಲಿ ಬೆಳಗಾವಿ ಉತ್ತರ ವಿಧಾನಸಭಾ ಕ್ಷೇತ್ರವು (ಕ್ಷೇತ್ರ ಸಂಖ್ಯೆ #11) ವಿಶಿಷ್ಟ ಸ್ಥಾನ ಪಡೆದಿದೆ. ಸಾಮಾನ್ಯ ಕ್ಷೇತ್ರದಲ್ಲಿ ಕಳೆದ 2023ರ ಕರ್ನಾಟಕ ವಿಧಾನಸಭಾ ಚುನಾವಣೆಯಲ್ಲಿ ಅತ್ಯಂತ ರೋಚಕ ಚುನಾವಣಾ ಕದನ ಜರುಗಿತ್ತು. ಮತ ಎಣಿಕೆಯ ಅಂತಿಮ ಹಂತದಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಜನಪ್ರಿಯ ನಾಯಕ ಆಸಿಫ್ ( ರಾಜು ) ಸೇಟ್ ಅವರು ಜನಾದೇಶ ಪಡೆಯುವಲ್ಲಿ ಯಶಸ್ವಿಯಾಗಿ ಪ್ರಸ್ತುತ ಶಾಸಕರಾಗಿ ಕರ್ತವ್ಯ ನಿರ್ವಹಿಸುತ್ತಿದ್ದಾರೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಅಂಕಿಅಂಶಗಳ ಪ್ರಕಾರ ಆಸಿಫ್ ( ರಾಜು ) ಸೇಟ್ ಅವರು ಒಟ್ಟು 69,184 ಮತಗಳನ್ನು ಗಳಿಸುವ ಮೂಲಕ ಶೇಕಡಾ 46.6% ಮತ ಹಂಚಿಕೆ ಪಡೆದಿದ್ದಾರೆ.

ಕಳೆದ ಚುನಾವಣೆಯ ಮತಗಳ ಲೆಕ್ಕಾಚಾರವನ್ನು ಪರಿಶೀಲಿಸಿದಾಗ, ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ ಆಸಿಫ್ ( ರಾಜು ) ಸೇಟ್ ಮತ್ತು ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ ಡಾ. Ravi ಬಿ. ಪಾಟೀಲ್ ನಡುವೆ ತೀವ್ರ ಸ್ಪರ್ಧೆ ಏರ್ಪಟ್ಟಿತ್ತು. ಅಂತಿಮವಾಗಿ ಆಸಿಫ್ ( ರಾಜು ) ಸೇಟ್ ಅವರು 4,231 ಮತಗಳ ಸ್ಪಷ್ಟ ಗೆಲುವಿನ ಅಂತರದೊಂದಿಗೆ ತಮ್ಮ ಎದುರಾಳಿ ಡಾ. Ravi ಬಿ. ಪಾಟೀಲ್ ಅವರನ್ನು ಪರಾಭವಗೊಳಿಸಿದರು. ಎರಡನೇ ಸ್ಥಾನ ಪಡೆದ ಬಿಜೆಪಿ (BJP) ಅಭ್ಯರ್ಥಿ ಡಾ. Ravi ಬಿ. ಪಾಟೀಲ್ ಅವರು 64,953 ಮತಗಳನ್ನು ಪಡೆದು ಗಮನಾರ್ಹ ಸಾಧನೆ ಮಾಡಿದರು. ಈ ಚುನಾವಣೆಯಲ್ಲಿ ಕ್ಷೇತ್ರದಲ್ಲಿ ಶೇಕಡಾ 75.4% ಮತದಾನ ದಾಖಲಾಗಿತ್ತು.

ಬೆಳಗಾವಿ ಉತ್ತರ ಕ್ಷೇತ್ರದ ಚುನಾವಣಾ ಇತಿಹಾಸವು ಅತ್ಯಂತ ವೈವಿಧ್ಯಮಯವಾಗಿದೆ. 1978ರಿಂದ 2023ರವರೆಗೆ ನಡೆದ ಒಟ್ಟು 11 ಸಾರ್ವತ್ರಿಕ ಚುನಾವಣೆಗಳಲ್ಲಿ ಪ್ರಮುಖವಾಗಿ ಕಾಂಗ್ರೆಸ್ (INC) (5 ಬಾರಿ), ಸಿಪಿಐ (CPI) (3 ಬಾರಿ), ಬಿಜೆಪಿ (BJP) (2 ಬಾರಿ), ಜನತಾ ದಳ (JD) (1 ಬಾರಿ) ಮತದಾರರ ಪ್ರಮುಖ ಬೆಂಬಲ ಪಡೆದುಕೊಂಡಿವೆ. ಗತಕಾಲದ ಚುನಾವಣೆಗಳ ಫಲಿತಾಂಶಗಳನ್ನು ನೋಡಿದರೆ 2018ರ ಚುನಾವಣೆಯಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ Anil ಎಸ್. Benake ಅವರು (+17,267 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2013ರ ಚುನಾವಣೆಯಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ Fairoz Nuruddin Saith ಅವರು (+18,210 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2008ರ ಚುನಾವಣೆಯಲ್ಲಿ ಕಾಂಗ್ರೆಸ್ (INC) ಪಕ್ಷದ Feroz Nuruddin ಸೇಟ್ ಅವರು (+3,373 ಮತಗಳ ಅಂತರ) ಹಾಗೂ 2004ರ ಚುನಾವಣೆಯಲ್ಲಿ ಬಿಜೆಪಿ (BJP) ಪಕ್ಷದ Sunil Vallapure ಅವರು (+1,018 ಮತಗಳ ಅಂತರ) ಯಶಸ್ವಿಯಾಗಿ ಶಾಸಕರಾಗಿ ಆಯ್ಕೆಯಾಗಿ ಜನಸೇವೆ ಸಲ್ಲಿಸಿದ್ದರು.

ಒಟ್ಟಾರೆಯಾಗಿ ಬೆಳಗಾವಿ ಉತ್ತರ ಶಾಸನಸಭಾ ಕ್ಷೇತ್ರವು ಮತದಾರರ ಪ್ರಬುದ್ಧ ತೀರ್ಪಿಗೆ ಹಾಗೂ ರಾಜಕೀಯ ಮರುಸಂಘಟನೆಗೆ ಸಾಕ್ಷಿಯಾಗಿದೆ. ಚುನಾವಣಾ ಆಯೋಗದ ಮುಕ್ತ ಮತ್ತು ನ್ಯಾಯಸಮ್ಮತ ದಾಖಲೆಗಳ ಆಧಾರದ ಮೇಲೆ ರಚಿತವಾದ ಈ ವರದಿಯು ಕ್ಷೇತ್ರದ ರಾಜಕೀಯ ಪ್ರಗತಿ ಹಾಗೂ ಮುಂದಿನ ದಿನಗಳ ರಾಜಕೀಯ ಪಥಕ್ಕೆ ದಿಕ್ಸೂಚಿಯಾಗಿದೆ.

ಮಾಹಿತಿಯ ಮೂಲಗಳು: ಚುನಾವಣಾ ಆಯೋಗ, ಸಂಬಂಧಿತ ಅಧಿಕೃತ ಮೂಲಗಳು
